荣悦E5刷机教程

荣悦 E5 刷机教程（根据视频整理）视频作者来源：https://www.bilibili.com/video/BV1e65y69E3L/

适用对象：荣悦 E5 / fortuneShip E5。
风险提示：刷机会清空数据，且有变砖风险。请只给自己的设备操作，提前备份资料、确保电量充足，并使用可信来源的刷机包。视频中部分文件名很长，下面以能辨认出的名称和用途为准；实际操作时以你手头刷机包里的文件为准。

一、准备工作

1. 所需文件

视频中用到的文件/目录大致如下：

  • 官改刷机包：荣悦E5百变系统V3_去除data加密_[adb调试83781工程模式打开...]
  • 展讯/紫光驱动：刷机驱动_SPD_Driver_R4.20.4201
  • 一键刷机脚本：[强卡模式C]一键刷机_会清空用户数据.bat
  • Magisk/面具：Magisk_28103_面具.apk
  • MT 管理器：MT2.64.apk 或视频里下载的 MT 管理器安装包
  • 模块包：荣悦E5解除热点数量限制+锁5GWIFI信道+固定热点IP模块v3.zip
  • UFI-TOOLS 模块/插件：UFI-TOOLS for Unisoc devices (4).zip
  • 可选升级包：荣悦E5百变系统V3升级到V3.5(开机状态打开adb刷).7z

2. 电脑环境

  • Windows 电脑
  • 可传数据的 USB 数据线
  • 刷机包路径尽量全英文，例如：D:\flash\E5\
    视频里特别强调：路径最好不要有中文，否则部分脚本/系统可能报错。
  • 刷机前可临时关闭 Windows Defender/杀毒软件的实时防护，避免脚本或二进制工具被误删。只在确认刷机包可信时这样做。

二、解压刷机包并安装驱动

  1. 将官改刷机包解压到英文路径。
  2. 打开解压后的目录。
  3. 进入 刷机驱动_SPD_Driver_R4.20.4201。
  4. 根据电脑系统运行驱动安装程序，例如：
    • DriverSetup.exe
    • 或 DPInst64.exe / DPInst32.exe
  5. 安装完成后，打开“设备管理器”备用，后面可以观察设备是否识别为 SPRD/Android 相关设备。

三、刷入官改系统

这一步会清空用户数据。视频里选择的是会清空数据的一键刷机脚本。

  1. 保持荣悦 E5 关机或准备进入刷机连接状态。
  2. 在刷机包目录中双击运行：
  1. 脚本窗口出现等待设备后，按住手机上“电源键上方的按键”（视频里手按的位置），同时插入 USB 数据线。
  2. 等待脚本开始跑进度条/开始写入分区后，再松开按键。
  3. 正常情况下，命令行会显示类似内容：
  1. 写入过程中不要拔线、不要关闭窗口。
  2. 刷完后等待设备自动重启，直到进入系统。

四、首次开机后打开工程模式和 ADB

  1. 进入系统后，打开拨号。
  2. 输入工程模式代码：
  1. 进入 EngineerMode 后，切到 DEBUGLOG 或调试相关页面。
  2. 打开以下开关：
    • USB Debug
    • 视频中出现的 ADB/调试相关开关；如果有 Delta Control，也按视频打开。
  3. 重新连接 USB，若手机弹出 USB 调试授权，请允许。

五、安装 Magisk 和 MT 管理器

视频中使用 AYA 工具连接并控制手机，也可以用其他 ADB 工具完成安装。

方法 A：用 AYA 安装

  1. 打开 AYA，选择设备 fortuneship E5。
  2. 等待手机画面出现在电脑上。
  3. 点击 AYA 工具栏里的 + 按钮安装 APK。
  4. 安装：
    • Magisk_28103_面具.apk
    • MT2.64.apk 或 MT 管理器 APK

六、修复 Magisk 环境

  1. 在手机上打开 Magisk。
  2. 如果弹出“需要修复运行环境/修复环境”之类提示，选择修复。
  3. 等待手机自动重启。
  4. 重启后再次确认 Magisk 可以正常打开。

八、进入 UFI-TOOLS Web 管理页

重启后，手机里会出现 UFI-TOOLS_WEB 相关应用/服务。第一次打开时，如果弹出通知权限，选择允许。

2. 无法访问插件商店时

如果机器没有插卡，可能访问不了插件商店。视频里的做法是先让手机连 Wi-Fi，再访问插件商店或在线功能。

九、热点管理设置

打开 Web 页后，进入 UFI-TOOLS v1.0.22 Beta E5，在 热点管理 页面可以设置和控制热点。

常见配置项：

  • SSID：热点名称，例如视频里使用 KanoHotspot
  • 密码：至少 8 位，例如 12345678
  • 安全类型：wpa2
  • 频段：2.4GHz
  • 信道：按需要选择，视频里演示了锁 5G Wi-Fi 信道/固定热点 IP 模块
  • 国家码：例如 CN

页面按钮用途：

  • 保存设置：保存热点配置
  • 立即启动：启动热点
  • 停止热点：关闭热点
  • 启动 USB 共享连接：开启 USB 网络共享
  • 停止 USB 共享连接：关闭 USB 网络共享
  • 刷新状态：刷新当前状态
  • 清除配置：清空已有配置

十三、常见问题

1. 脚本一直卡在 waiting for device

  • 确认数据线支持传数据。
  • 重新安装 SPD_Driver_R4.20.4201 驱动。
  • 换 USB 口，优先使用电脑后置 USB 口。
  • 重新按视频方式：按住电源键上方按键，再插入数据线，等进度开始后再松开。
  • 打开设备管理器，观察是否出现 SPRD、U2S Diag、Android Phone 等设备。

2. Magisk 提示修复环境

按提示修复即可，修复后通常会自动重启。重启后再继续刷模块。

3. Web 管理页打不开

  • USB 方式确认访问：http://192.168.42.1:2333
  • Wi-Fi/热点方式确认访问：http://192.168.43.1:2333
  • 确认模块已在 Magisk 中安装并重启。
  • 确认手机端 UFI-TOOLS_WEB 已启动，通知权限已允许。
  • 确认 PC 和手机处于对应连接方式下。

4. 插件商店打不开

视频里是因为机器没插卡、没有网络。先让手机连接 Wi-Fi，或插入可联网 SIM 卡，再重新打开插件商店。

5. 杀毒软件误报/删除脚本

刷机包里含有批处理和底层刷写工具，可能被误报。只在确认来源可信时临时关闭防护，刷完后再恢复。

十四、完成检查

全部完成后，确认以下状态：

  • 手机能正常开机进入系统。
  • Magisk 能正常打开。
  • 模块安装后已重启。
  • 浏览器能打开 192.168.42.1:2333 或 192.168.43.1:2333。
  • Web 页里能控制热点开启/关闭。
  • 实体按键触发规则保存后，已启动监听，按键可以执行对应命令。
